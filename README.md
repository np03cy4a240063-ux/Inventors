# ReInvent v2 - Smart Inventory Management

## Overview
This is the second version of the ReInvent splash page, now featuring full user authentication (Login and Sign Up) and a refactored landing page.

## Project Structure
-   `frontend/`: Static HTML/CSS/JS files for Splash, Login, and Sign Up.
-   `backend/`: Node.js server with Express and MySQL schema.
-   `integrated/`: The merged application serving the frontend and handling real-time authentication.

## Debugging Notes (UI/UX)
-   **Splash Page Refactor**: Successfully removed personal names ("Rekha Bhujel", "Apekshya Pandeya") while maintaining layout integrity. Optimized the blue panel's responsive height for better mobile viewing.
-   **Auth Page Design**: Recreated the dual-column split layout with pixel precision. Implemented radial gradients for the form background pattern and used `24px` rounded corners for a premium, modern aesthetic.
-   **Form Validations**: Added password matching logic and field requirement checks to enhance user experience.
-   **Visual Consistency**: Unified icon sets (Font Awesome) and button styles across all pages for a cohesive brand identity.
